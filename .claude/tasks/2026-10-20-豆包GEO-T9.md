## 关键决策与理由
- 头条号/抖音号是 P0 渠道，官网降为 P1：新榜 2025-12 数据，豆包 TOP5 信源里有 3 个是字节系
- 只在用户端测（App 为主），不用 API：用户端和 API 的信源差别大
- 每题测 3 次、分散在不同日期；AI 编码先和人工编码比一致率（客观字段 ≥95%、主观字段 ≥90%）
- 全自动提问不做：豆包协议 §8.4/§6.2 有爬虫和抓取条款，属于灰色地带，需法务确认
- ~~监测工具先试用 Answerbit~~ → 2026-10-20 改为自建免费的内部版本（Answerbit 收费）。结构分两层：豆包、元宝在用户端半自动采集（主指标）+ 有联网能力的 API 全自动采集（趋势参考），两层的数据分开统计
- 各家 API 的联网能力：Kimi `$web_search` 有官方文档（每次调用 0.03 元，需关闭思考模式）；DeepSeek、千问、混元还没核实
- 豆包有官方的「豆包助手 API」（自称「与豆包同源」「豆包 App 同款」能力，包括联网搜索）：Responses API，请求头 `ark-beta-doubao-app: true`，模型 `doubao-seed-2-1-pro-260915`，有 `user_location` 参数，按次计费不收 token 费。**文档没承诺回答和 App 一致**；限制是模型参数不能调，内容源、搜索轮次也不能自定义。新榜「API ≠ 用户端」的数据是 2025-12 测的，可能不适用于这个 API → 待办：做 App 和这个 API 的成对对照
- 联网内容插件 / 豆包搜索 Custom 版：sources 可选 toutiao（头条图文）、douyin（抖音百科）、moji、doubao（只能单独配置）；返回的 annotations 里有 url_citation（title/url/site_name/publish_time）
