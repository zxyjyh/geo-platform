## InsGEO 已验证事实（来自真实接口数据）
- 品牌指数 = 0.5×可见度 + max(0,(竞品数+1−排名)/竞品数×30) + 0.2×引用比；用首页数据复算 61.86 vs 显示 61.9 ✓
- 增长指数 = 品牌指数日序列线性回归斜率（前端文案）
- 每天约 71–84 条回答（8 平台合计），每平台每轮连跑 2 次，09:00 / 15:00 两轮；7 天 549 条
- 实际只监测 1 个场景「澳门外卖平台推荐」、约 2 个提问；首页「1.5k 运营场景与洞察点」= own_alias 1478，不是提问数
- 元宝的回答 think_content 含「调用 __finish」「每个事实段引用一个来源」→ 自建 Agent + API 模拟，非元宝 App（高把握）；all-models 里元宝 = [deepseek, hunyuan]；豆包回答文风「根据查询结果…信息来源：」也像 API（中把握）
- 引用周期：首次出现耗时 = first_appeared_at − created_at；频率 = 出现次数/跨度天数；能量 = 出现次数/活跃天数（已用数据复算）
- 引用 URL 有全局库（search_key = URL 哈希，created_at = 首次入库）
- 情感模块抽出的澳觅事实互相矛盾：商户 5300/1600/5500 家、市占率 90%
- 智能投放 = 软文发稿市场（media/search：媒体名、价格 315 元、收录率、「99%都能收录」）

## 可借鉴（汇总两家，待用户选）
1. 每题每轮连跑 2 次 / 一天多轮（两家都这么做）——依赖 API 单价（未查）
